## Important files

### main.py
Main backend entry point.  
Handles API requests and triggers the analysis pipeline.

### analyzers.py
Responsible for executing SmartBugs and running:

Slither  
Mythril  
Oyente  

This module launches the command:

```bash
smartbugs --files <contract.sol> \
--tools slither oyente \
--json \
--overwrite \
--results <output_dir>
```

### report_parser.py
Reads the JSON reports generated by SmartBugs and converts them into structured vulnerability data.

### debater.py
Uses LLM-based reasoning to validate vulnerability findings.

### summarizer.py
Generates human-readable summaries of detected vulnerabilities.

### fixer.py
Attempts to generate a repaired version of the vulnerable smart contract.

## **Installing SmartBugs**

Clone the SmartBugs framework:

```bash
git clone https://github.com/smartbugs/smartbugs.git
cd smartbugs
```

Install Python dependencies:

```bash
pip install -r requirements.txt
```

Download Docker images for analyzers:

```bash
python smartbugs.py --pull
```

This command pulls Docker images for tools including:

Slither

Oyente

Mythril

Manticore

AutoSCAR currently uses:

Slither  

Oyente

Mythril

## **Configure SmartBugs Path**

Inside analyzers.py, SmartBugs is executed using a predefined path.

Example:

```python
SMARTBUGS_EXEC = "/home/pankaj/bin/smartbugs"
```

You must update this path to match your SmartBugs installation.

Example:

```python
SMARTBUGS_EXEC = "/home/user/smartbugs/smartbugs.py"
```

Alternatively create a symbolic link:

```bash
sudo ln -s /path/to/smartbugs/smartbugs.py /home/pankaj/bin/smartbugs
```

## **Internal Execution Process**

When a contract is submitted:

Step 1 — File Upload  
Contract is stored in:

```
uploads/
```

Step 2 — SmartBugs Execution  
AutoSCAR runs:

```bash
smartbugs \
--files contract.sol \
--tools slither oyente \
--json \
--overwrite \
--results results_dir
```

Step 3 — Docker Analysis  
SmartBugs launches Docker containers for:

Slither

Oyente

Mythril

Step 4 — JSON Report Generation  
Each analyzer produces vulnerability reports.

Step 5 — Report Parsing  
report_parser.py extracts vulnerability information.

Step 6 — LLM Validation  
debater.py evaluates vulnerability results.

Step 7 — Summarization  
summarizer.py produces human-readable explanations.

Step 8 — Fix Generation  
fixer.py generates repaired smart contract code.
